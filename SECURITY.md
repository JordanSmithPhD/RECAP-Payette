# Security and sensitive-data reports

Do not open a public issue containing credentials, private media, precise
camera locations, participant information, or other restricted material.

Use GitHub's private vulnerability-reporting feature for security concerns.
For an accidental sensitive-data commit, identify the affected path and commit
without reproducing the sensitive value in a public issue. Rotate exposed
credentials immediately; removing a later commit does not invalidate a secret
or guarantee removal from existing clones and caches.
